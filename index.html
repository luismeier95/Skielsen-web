NEU ODER REVANCHE?

Eine Gruppe ist kein eigener Turniertyp. Du startest ein neues Turnier oder eine Revanche. Eine Revanche erzeugt bzw. verlängert automatisch eine Turnierserie; eine feste Gruppe kann dieser Serie auch später zugeordnet werden.

SERIE ≠ GRUPPE. Die Serie verbindet Revanchen miteinander. Eine Gruppe ist die dauerhafte Community darüber und kann jederzeit nachträglich mit einer bestehenden Serie verbunden werden. Historische Ergebnisse bleiben am User und am Turnier – niemand verliert Statistiken.
Wenn du bereits eine feste Gruppe hast, startest du das Turnier direkt aus der Gruppenkarte auf „MEIN SKIELSEN“. Dort wird der Gruppenkontext zusätzlich gesetzt.
